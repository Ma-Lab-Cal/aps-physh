# Discipline assignment

**What this is:** independent, from-scratch discipline assignment for 30 papers, using only
the title and abstract below (some early papers are title-only). Your judgments are
compared against each other and against the automated labels; nothing here shows you any
existing label.

**How to do it (self-contained):**
1. Work alone. Do not confer with anyone — including the other annotators and the
   paper's authors — do not use AI tools, do not look up the papers or any labels.
   Title + abstract only.
2. For each paper, write 1-3 codes from the table below on the `Disciplines:` line,
   primary first, comma-separated (e.g. `Disciplines: NUC` or `Disciplines: CMP, AMO`).
   One code is the normal case; add a second only if the paper genuinely advances both
   fields.
3. Judge era-appropriately: what is this paper about, expressed in the modern scheme.
   About one minute per paper; ~30-40 minutes total.
