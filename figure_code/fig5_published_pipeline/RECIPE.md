# Recipe: regenerating the published Fig. 5 (and the revised version)

For Khoa — how the published `fig5.png` is actually produced, how to regenerate
it from local files, and what the public repo's plotting script would need to
match it.

## 0. Provenance

The published figure was generated by the PI's Colab notebook (export:
`reports/fig5.py`), NOT by `aps-physh-main/plotting/plot_concept_trends.py`.
Pipeline (from the notebook):

1. **<= 2016**: five "backfilled" model-label runs (`backfilled_run_{1..5}.jsonl`,
   fields `item_id, item_key, year, doi, journal, predicted_disciplines,
   predicted_concepts`), downloaded from Drive folder
   `1ktDU41mW4kX6D64duXXFpNfz1y98nb-T`, with `backfilled_run_1.jsonl` then
   **replaced** by file id `1if2eDpISyOacSnTp63Oq8DcRRMihWCTn` (May 2026).
   Rows with `year >= 2017` are ignored.
2. **2017+ ("gold")**: author-assigned PhySH concepts from consolidated APS
   metadata (`aps_dataset_metadata_2025.jsonl`, Drive id
   `1qLlsCIDqCotmolGBdmlAi8f_BJpyc6B-`), concept UUIDs mapped to names via
   `physh.json` (Drive id `1m0pGoXYzX4ESIowJD8lW4UMPrgxV3loD`). Filters:
   skip `journal.id == "PHYSICS"`; skip erratum/comment/reply/etc. title
   prefixes; **skip papers with no mapped concepts (they are excluded from the
   per-year totals too — the 2017+ denominator is "papers with >= 1 author
   concept"**, 187 451 papers 2017-2025). Year = first `(18|19|20)\d{2}` match
   in the `date` string.
3. **Counting method `average`**: for each concept-year, the numerator is the
   mean paper count over the five runs (sum over papers of k/5, k = number of
   runs listing the concept); pre-2017 denominator = all 581 475 papers in the
   runs with year <= 2016. Gold years use plain counts. Share (%) per year,
   then a 3-year centered rolling mean (`min_periods=1`).
4. Concepts/styling: see section 3.

## 2. Commands

```bash
cd "analysis/fig5_repro"

# one-time aggregation caches (public-data variant)
python3 plot_concept_trends_published.py --stage aggregate --data public
# optional: exact notebook inputs, if the Drive files are present
FIG5_DRIVE_RUNS="/tmp/fig5_drive/backfilled runs" \
python3 plot_concept_trends_published.py --stage aggregate --data drive

# figures
python3 plot_concept_trends_published.py --stage plot --data drive  --output fig5_reproduced.png
python3 plot_concept_trends_published.py --stage plot --data public --output fig5_reproduced_publicdata.png
python3 plot_concept_trends_published.py --stage plot --data drive --revised --output fig5_revised.png
```

Environment: python 3.12, pandas 2.2, numpy 1.26; matplotlib 3.8.4 and 3.10.0
give identical output. Letters need an Arial-metric font (uses
`/usr/share/fonts/truetype/croscore/Arimo-Regular.ttf`).

## 3. What the public repo's `plotting/plot_concept_trends.py` would need to match the paper

Data/pipeline:
- Merge rule: model runs for year <= 2016, author-label ground truth for 2017+
  (with the gold filters/denominator of section 0.2). The repo script currently
  plots runs only, so curves die at 2016.
- Counting: mean over the five runs (`average`), not the `min_run_count=2`
  majority vote. This lowers most curves (majority counting overweights
  2-of-5 assignments); it is also what the caption states.
- Include all run rows (the backfill covers every article type pre-2017);
  the v2 research-type-filtered `runs/` files change the denominator
  (558 875 vs 581 475) and visibly raise all shares.
- Ship a `year` (or rely on a DOI->year metadata file, as the script already
  does). Years must cover 2025.

Panel spec (differences from the repo script's `FIGURE5_PANELS`):
- Panel (b): `Deep inelastic scattering` (discovery 1968, Nobel 1990), NOT
  `Nuclear magnetic resonance`; CMB discovery year 1964 (repo has 1965);
  X-ray diffraction 1912/1914 and Graphene 2004/2010 unchanged.
- Panel (c) analytical list: `Mathematical physics methods` (exact PhySH
  concept name; the repo's `Mathematical physics` is a DIFFERENT concept),
  plus `Perturbation theory`, `Green's function methods`. Computational list
  unchanged. Legend labels are concept-derived composites
  ("Mathematical physics + Perturbation\ntheory + Green's function",
  "DFT + Monte Carlo + Tensor networks"), with "QCD" as the short label in (a).
- Colors: matplotlib `tab10` indices [0,1,2,3,7]; panel (c) uses [0,1]; panel
  (d) swaps the colors of Spintronics and Gravitational wave sources (so
  Spintronics = red, Gravitational wave sources = gray).
- Layout/style: fig 7.1 x 3.8 in, margins l/r/b/t = 0.085/0.985/0.085/0.975,
  wspace 0.20, hspace 0.08; lw 1.0, curve alpha 0.80; event lines lw 0.75,
  alpha 0.40, dashes (0,(4,2)); inner titles fs 7 (panel (b)'s on a white
  alpha-0.72 rounded patch, as is its legend); legends fs 6; y-ticks per panel:
  (a) 0..16 step 4, top tick at 90 % height; (b) 0..5 step 1 at 87 %;
  (c) 0..8 step 2 at ~100 %; (d) 0..2 step 1 at 90 %; y floor = -4 % of top
  tick; all four spines visible; top-row x tick labels hidden.
- Saving: `savefig.dpi = 900`. The published PNG additionally has panel letters
  (a)-(d) in ~10 pt Arial (added OUTSIDE the notebook, hand-placed) and is an
  ink-tight manual crop: equivalent to rendering the full 6390 x 3420 canvas
  and cropping to offset (189, 34), size 6115 x 3380 - which is what
  `plot_concept_trends_published.py` does.

## 4. Revised figure (Mathematical physics removed)

`--revised` drops `Mathematical physics methods` from the panel (c) analytical
aggregate; the legend label becomes "Perturbation theory + Green's function"
(one line). Nothing else changes (bit-identical outside panel (c)).
